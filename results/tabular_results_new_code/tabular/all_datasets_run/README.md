## Results

Job completed 2026-06-24, elapsed 06:59:25. n=1491 (DUKE+ISPY1+ISPY2+NACT), 5-fold CV.

Full per-arm summary: `$SV_DATA_DIR/tabular/all_datasets_run/ablation_summary.csv`

### Key observations

- Baseline (clinical+tumor_size LR=0.588) is the top-performing LR arm.
- No vessel feature block improves over baseline for LR; all are flat or negative.
- Kinematic+LR (0.586) is within noise of baseline; nested tuning consistently selects k_kin=0–16 across folds.
- vessel_all+XGB (0.564) slightly exceeds its baseline XGB (0.550) but remains below LR baseline.
- XGB underperforms LR across all arms on this cohort.
